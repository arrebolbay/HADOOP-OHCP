# 数据说明（随仓库提供）

本目录包含项目运行所需的**全量真实公开数据**：

| 目录 | 内容 | 规模 |
| --- | --- | --- |
| `raw/daily/` | 全国城市空气质量日文件（2024 年，361 天，5 天源站缺档） | 约 135MB |
| `raw/chunks/` | `step02` 生成的长表按月分片（12 个） | 约 189MB |
| `cache/cleaned/` | `step03` 清洗后的分片（12 个，Agent 默认读取） | 约 231MB |
| `cache/cache_*/` | 日均值等查询缓存（加速 Agent） | 约 5MB |
| `reference/` | 城市→省份参考表、行政区划缓存 | 约 2MB |

总计约 **560MB**。数据来源：全国城市空气质量实时发布平台公开日文件
（quotsoft.net/air 归档；原始发布机构为中国环境监测总站/国家城市空气质量实时发布平台）。
